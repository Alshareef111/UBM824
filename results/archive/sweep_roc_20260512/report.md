## Decision rule

Per cluster touch at bar T: look up |close_{T-1} - close_{T-1-N}| in points.
- |ROC_pts(N)| ≥ threshold → TREND (invert direction)
- |ROC_pts(N)| < threshold → FADE (locked-baseline direction)

**Scale note:** Panama prices range ~6,000 (2019) → ~25,000 (2026). Fixed point
threshold means relative threshold (as % of price) decreases ~4× across dataset.
If qualifying region appears regime-biased, this scale effect is a candidate cause.
